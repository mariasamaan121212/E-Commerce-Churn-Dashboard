# 📊 E-Commerce Customer Churn & Retention Dashboard

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://e-commerce-churn-dashboard-kqk2hszgrd29v3u7do2baw.streamlit.app/)

An end-to-end Machine Learning web application designed to predict customer churn risks and recommend actionable retention strategies for e-commerce businesses.

🚀 **Live Interactive Demo:** [Launch Dashboard App](https://e-commerce-churn-dashboard-kqk2hszgrd29v3u7do2baw.streamlit.app/)

---

## 📌 Business Overview
Customer retention is vital for e-commerce profitability. This application analyzes transactional behaviors across 138K+ records to identify churn-prone buyers early, enabling marketing teams to deploy targeted loyalty incentives.

## ⚡ Model Performance & Key Drivers
- **Algorithm:** XGBoost Classifier
- **Accuracy:** 62.39%
- **ROC-AUC Score:** 0.6686
- **Top Business Drivers:** Order Frequency (37.9%), Total Profit, Monetary Value, Customer Ratings, and Delivery Days.

## ✨ Key Features
- **🎨 Modern Dark/Neon UI:** Custom CSS Glassmorphism styling optimized for high-end portfolio demonstration.
- **🎯 Single Risk Assessment:** Real-time individual customer churn scoring with instant business action recommendations.
- **📁 Enterprise Batch Scoring:** CSV dataset upload support for bulk scoring of thousands of customer profiles.

## 🛠️ Tech Stack
- **Machine Learning:** Python, XGBoost, Scikit-Learn, Pandas, NumPy, Joblib
- **Web Framework & UI:** Streamlit, Custom CSS
- **Deployment:** Streamlit Community Cloud, GitHub
